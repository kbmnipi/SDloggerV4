# 02 — Акселерометр BMI160 (модуль GY-BMI160)

Краткая выжимка из даташита Bosch **BMI160** (`BST-BMI160-DS000`) для написания драйвера. Гироскоп полностью отключён (`SUSPEND`) для экономии батареи и места в FIFO.

---

## 1. Интерфейс SPI1 и обязательные тайминги

* **Режим:** SPI Mode 3 (**`CPOL = 1`, `CPHA = 1`**) или Mode 0 (`0, 0`), старший бит первым (MSB first), 8 бит. Используем **Mode 3**.
* **Частота:** до 10 МГц. Для проводов 8–10 см использовать **5.25 МГц** (`APB2 84 / 16`), при сбоях — снизить до **2.625 МГц** (`84 / 32`).
* **Формат команды (1-й байт):**
  * Чтение: `0x80 | (addr & 0x7F)`
  * Запись: `addr & 0x7F`
  * **Автоинкремент адреса включён всегда** при удержании `CS = 0` (кроме регистра данных `FIFO_DATA (0x24)` — при чтении из `0x24` адрес не растёт, а последовательно выгружается буфер FIFO).
* **КРИТИЧЕСКИЙ ТАЙМИНГ (`t_IDLE`):**
  * Когда датчик в режиме `SUSPEND` (сразу после включения питания или после Soft Reset `0xB6`), минимальная пауза с высоким `CS = 1` между двумя SPI-транзакциями составляет **450 мкс**! Поэтому при инициализации после каждого командного байта делать задержку **`HAL_Delay(5)`** (или минимум 1 мс).
  * После выхода акселерометра в `Normal Mode` (`CMD = 0x11`) минимальная пауза `CS = 1` между транзакциями — **2 мкс** (при 84 МГц достаточно небольшой паузы ~3–5 мкс перед следующим `CS = 0`).

## 2. Рабочие регистры BMI160

| Адрес | Имя | Тип | Назначение |
|---|---|---|---|
| `0x00` | `CHIP_ID` | R | Идентификатор датчика, всегда **`0xD1`** |
| `0x02` | `ERR_REG` | R | Коды ошибок конфигурации (`err_code[4:1]`, `fatal_err` бит 0) |
| `0x03` | `PMU_STATUS` | R | Текущий режим питания: биты `[5:4]` `acc_pmu_status` (`01` = Normal), биты `[3:2]` `gyr_pmu_status` (`00` = Suspend) |
| `0x12..0x17` | `DATA_14..DATA_19` | R | Прямые регистры ускорения (X_L, X_H, Y_L, Y_H, Z_L, Z_H) |
| `0x1B` | `STATUS` | R | Флаг `drdy_acc` (бит 7) |
| `0x20` | `TEMPERATURE_0` | R | Младший байт температуры (16 бит, разрешение `1/512 °C`, `0x0000` = **23 °C**) |
| `0x21` | `TEMPERATURE_1` | R | Старший байт температуры (`int16_t` в паре с `0x20`) |
| `0x22` | `FIFO_LENGTH_0` | R | Младший байт числа байт в FIFO (`fifo_byte_counter[7:0]`) |
| `0x23` | `FIFO_LENGTH_1` | R | Старшие 3 бита счётчика байт FIFO (`fifo_byte_counter[10:8]`, маска `0x07`, макс. 1024 байта) |
| `0x24` | `FIFO_DATA` | R | Окно чтения FIFO (читать пачкой `N` байт за один цикл `CS = 0`) |
| `0x40` | `ACC_CONF` | R/W | Полоса фильтра `acc_bwp[6:4]` и частота выборки `acc_odr[3:0]` |
| `0x41` | `ACC_RANGE` | R/W | Диапазон измерения (`0x03` = ±2g, `0x05` = ±4g, `0x08` = ±8g, `0x0C` = ±16g) |
| `0x46` | `FIFO_CONFIG_0` | R/W | Порог водяного знака `fifo_water_mark` (в шагах по **4 байта**!) |
| `0x47` | `FIFO_CONFIG_1` | R/W | Включение источников в FIFO: `fifo_acc_en` (бит 6), `fifo_header_en` (бит 4) |
| `0x50` | `INT_EN_0` | R/W | Включение прерываний (оставить `0x00`) |
| `0x51` | `INT_EN_1` | R/W | `int_fwm_en` (бит 6 — прерывание по порогу FIFO `FWM`) |
| `0x53` | `INT_OUT_CTRL` | R/W | Настройка пина `INT1`: `int1_output_en` (бит 3), `int1_lvl` (бит 1: `1` = Active HIGH) |
| `0x56` | `INT_MAP_1` | R/W | Маршрутизация на `INT1`: `int1_fwm` (бит 6) |
| `0x7E` | `CMD` | W | Команды: `0xB6` = Soft Reset, `0x11` = Accel Normal Mode, `0xB0` = Очистить FIFO |
| `0x7F` | `SPI_WAKEUP` | R | Фиктивный адрес: одиночное чтение `0xFF` переводит интерфейс из I2C в SPI |

## 3. Готовые настройки (`config.h`)

**Рабочий профиль по умолчанию: 1600 Гц, ±16 g, фильтр OSR2 (~324 Гц):**
* `ACC_CONF (0x40)` = **`0x1C`** (`acc_us = 0`, `acc_bwp = 001` → OSR2 срез -3 дБ на **324 Гц**, `acc_odr = 1100` → **1600 Гц**).
  *(Варианты фильтра для 1600 Гц: `0x0C` = OSR4 / 162 Гц; `0x1C` = OSR2 / 324 Гц; `0x2C` = Normal / 684 Гц).*
* `ACC_RANGE (0x41)` = **`0x0C`** (±16 g, точный масштаб **2048 LSB/g** = `488` мкg/LSB).
* `FIFO_CONFIG_0 (0x46)` = **`0x0E`** (`14 × 4 = 56 байт` = **8 фреймов** по 7 байт → прерывание каждые 5.0 мс).
* `FIFO_CONFIG_1 (0x47)` = **`0x50`** (`fifo_acc_en = 1`, `fifo_header_en = 1`, гироскоп/магнитометр/время выключены).
* `INT_EN_1 (0x51)` = **`0x40`** (`int_fwm_en = 1` — прерывание по watermark FIFO).
* `INT_MAP_1 (0x56)` = **`0x40`** (`int1_fwm = 1` — вывести FWM на пин `INT1`).
* `INT_OUT_CTRL (0x53)` = **`0x0A`** (`int1_output_en = 1`, `int1_lvl = 1` Active HIGH, Push-Pull).

**Быстрая смена частоты / диапазона в `config.h`:**
* Для **800 Гц (фильтр OSR2 ~162 Гц, ±16 g):** `ACC_CONF = 0x1B` (`acc_odr = 1011` → 800 Гц).
* Другие диапазоны (`ACC_RANGE`):
  * **`0x03`** → ±2 g (`16384 LSB/g`, `61` мкg/LSB)
  * **`0x05`** → ±4 g (`8192 LSB/g`, `122` мкg/LSB)
  * **`0x08`** → ±8 g (`4096 LSB/g`, `244` мкg/LSB)
  * **`0x0C`** → ±16 g (`2048 LSB/g`, `488` мкg/LSB)

## 4. Порядок запуска и вычитывания FIFO

**Строгий порядок инициализации (соблюдаем `t_IDLE`!):**
1. **Переключение в SPI:** выполнить одиночное чтение `0x7F` (`CS=0`, отправить `0xFF`, прочитать 1 байт, `CS=1`), выждать **5 мс**.
2. **Программный сброс:** записать `CMD (0x7E) = 0xB6`, выждать **10 мс** (после сброса интерфейс снова в I2C!).
3. **Повторное переключение в SPI:** выполнить одиночное чтение `0x7F`, выждать **5 мс**.
4. **Проверка ID:** прочитать `CHIP_ID (0x00)` — должно быть **`0xD1`** (если нет — ошибка №1).
5. **Включение акселерометра:** записать `CMD (0x7E) = 0x11` (Accel Normal Mode), выждать **5 мс**. Прочитать `PMU_STATUS (0x03)` — биты `[5:4]` должны быть `01` (`(status & 0x30) == 0x10`).
6. **Конфигурация:** записать `ACC_CONF (0x40)`, `ACC_RANGE (0x41)`, `FIFO_CONFIG_0 (0x46)`, `FIFO_CONFIG_1 (0x47)`, `INT_EN_1 (0x51)`, `INT_MAP_1 (0x56)`, `INT_OUT_CTRL (0x53)`.
7. **Очистка и прогрев:** записать `CMD (0x7E) = 0xB0` (Flush FIFO), выждать **50 мс** до старта записи.

**Безопасное чтение FIFO через DMA (пакетное):**
* В отличие от LIS3DSH, у BMI160 весь накопленный буфер читается **одной непрерывной DMA-транзакцией** из регистра `0x24` (`CS = 0` → отправить `0xA4` (`0x80 | 0x24`) → принять `N` байт по DMA → `CS = 1`).
* **Порядок вычитки при срабатывании `INT1` (`PB5`):**
  1. Убедиться, что DMA SPI1 свободен (Quiesce: потоки остановлены, `RXDMAEN`/`TXDMAEN` сброшены, `SPI1->DR` пуст).
  2. Прочитать 2 байта `FIFO_LENGTH_0..1` (`0x22`, `0x23`): `fifo_bytes = len0 | ((len1 & 0x07) << 8)`.
  3. Если `fifo_bytes < 7` — выйти (прерывание снято). Если `fifo_bytes >= 1015` (буфер почти полон, 1024 байта) — выставить флаг `SENSOR_OVR`.
  4. Ограничить размер одной DMA-вычитки размером приёмного буфера (`N = min(fifo_bytes, 252)` — кратно 7 байтам) и запустить SPI1 RX/TX DMA из `0xA4`.
* **Разбор фреймов в прерывании завершения SPI1 DMA (`spi_rx_buf`):**
  * Двигаемся по принятому буферу `idx`:
    * Байт заголовка `hdr = buf[idx]`:
    * **`0x84` (Regular Accel Frame):** за ним идут 6 байт `{XL, XH, YL, YH, ZL, ZH}` — копируем 6 байт в текущий слот кольцевого буфера SD, `idx += 7`.
    * **`0x80` (Empty / Overread Frame):** конец валидных данных в FIFO, останавливаем разбор цикла.
    * **`0x40` (Skip Frame):** заголовок + 1 байт счётчика пропущенных сэмплов (`buf[idx+1]`), `idx += 2` (ставим флаг `SENSOR_OVR`).
    * **`0x44` (Sensortime Frame):** `idx += 4` (игнорируем).
    * **`0x48` (FIFO Config Change):** `idx += 2` (игнорируем).
    * Любой другой заголовок (сбой SPI) — прерываем разбор пакета.
* **Страховка по таймеру (10 мс):** в основном цикле раз в 10 мс проверять `FIFO_LENGTH`. Если `fifo_bytes >= 56` и прошло > 12 мс без чтения — принудительно запустить вычитку.
* **Сброс при сбое SPI/DMA:** записать `CMD (0x7E) = 0xB0` (Flush FIFO), выждать 20 мс.

## 5. Температура (`OUT_T` для блока SD)

У BMI160 температура 16-битная (`0x20..0x21`), где `0x0000` = **23 °C**, а шаг `1/512 °C`. Чтобы записать привычный целый градус `int8_t temp_i8` в заголовок блока SD, достаточно прочитать `TEMPERATURE_1 (0x21)` (старший байт, шаг `256/512 = 0.5 °C`):
`int8_t temp_c = (int8_t)(23 + ((int8_t)temp_msb / 2));`
